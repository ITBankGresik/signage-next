Fondasi
Design Tokens
Semua nilai visual — warna, spasi, radius, shadow, durasi — didefinisikan sebagai CSS custom properties. Gunakan token ini secara langsung; jangan hardcode nilai mentah.
Cara penggunaan tokenCSS Variables
/* ✅ Benar — gunakan token */ .tombol { background: var(--blue-700); color: var(--text-inverse); padding: var(--space-2) var(--space-4); border-radius: var(--radius-md); transition: all var(--dur-fast) var(--ease-out); } /* ❌ Hindari — hardcode langsung */ .tombol { background: #185FA5; /* tidak adaptive dark mode */ padding: 8px 16px; /* tidak konsisten dengan skala */ }

Motion & Transisi
Tiga token durasi dan dua easing yang mencakup semua kasus UI. Jangan animasi lebih dari opacity dan transform untuk performa terbaik.
TokenNilaiKegunaan
--dur-fast100msHover state, aktif tombol, badge muncul
--dur-base150msToggle, dropdown buka, tab switch
--dur-slow250msModal masuk, panel geser, transisi halaman
--ease-outcubic-bezier(0,0,.2,1)Elemen masuk layar (decelerate)
--ease-in-outcubic-bezier(.4,0,.2,1)Elemen bergerak antar posisi
/* Pola standar transisi UI */ .tombol { transition: background var(--dur-fast) var(--ease-out), transform var(--dur-fast) var(--ease-out); } .tombol:active { transform: scale(0.98); } /* Ticker player — animasi scroll tak terbatas */ @keyframes ticker-scroll { from { transform: translateX(0); } to { transform: translateX(-50%); } } .ticker-text { animation: ticker-scroll 22s linear infinite; }
